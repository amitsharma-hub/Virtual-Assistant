# 🤖 Virtual Assistant

An intelligent AI-powered Virtual Assistant built using **HTML, CSS, and JavaScript**. This assistant interacts with users through voice commands, provides spoken responses, performs various browser tasks, and can search the web for answers when needed.

---

🚀 Live Demo

Live Website: [amit-streaming-website.netlify.app](https://amit-virtual-assistant.netlify.app/)

---

## 🚀 Features

- 🎤 Voice Recognition (Speech-to-Text)
- 💬 Real-time conversation with users
- 🌐 Google Search integration for unknown queries
- 🕒 Tells current time and date
- 📅 Opens Calendar
- 🔍 Searches anything on Google
- ▶️ Opens YouTube and plays videos
- 📧 Opens Gmail
- 🗺️ Opens Google Maps
- 🌦️ Answers general questions
- 📱 Responsive and clean user interface

## ⚙️ How It Works

1. Open the website.
2. Click the microphone button.
3. Speak your command.
4. The assistant converts your voice into text using the **Speech Recognition API**.
5. JavaScript processes the command.
6. If the command matches a predefined action, it performs that task instantly.
7. If the query is not predefined, the assistant automatically redirects the search to Google and provides relevant results.
8. The assistant also responds using voice through the **Speech Synthesis API**.
